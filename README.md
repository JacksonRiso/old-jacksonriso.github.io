# Jackson Riso Consulting

Personal website for Jackson Riso, Business Process & Automation Consultant.

## About

This is a Jekyll-based static site hosted on GitHub Pages, migrated from Squarespace.

## Development

### Prerequisites
- Ruby 2.7+
- Bundler
- Jekyll

### Local Setup

```bash
# Install dependencies
bundle install

# Run local server
bundle exec jekyll serve

# View at http://localhost:4000
```

### Building

```bash
bundle exec jekyll build
```

## Migration

See [claude.md](claude.md) for the complete migration plan from Squarespace to Jekyll.

## Deployment

This site is automatically deployed to GitHub Pages when changes are pushed to the main branch.
